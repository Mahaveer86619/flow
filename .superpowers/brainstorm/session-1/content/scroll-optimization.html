Part 1: Scroll Optimization

Ensuring 60+ FPS during home screen interaction

The Fixes

  • ListView.builder — Only render what's visible
  • Disk Cache Sizing — Stop wasting RAM on high-res thumbnails
  • Repaint Boundaries — Isolate card rendering from list scroll
  • Lazy Carousels — Disable idle animations

Current Issues

  • Heavy widget tree re-builds
  • Uncached remote images blocking main thread
  • Excessive Ticker updates
Widget Tree Architecture
HomeScreen (CustomScrollView)
  └ SliverMainAxisGroup (Shelf)
     └ SectionHeader
     └ SliverToBoxAdapter -> ListView.builder
        └ RepaintBoundary
          └ SongCard (Optimized Images)
