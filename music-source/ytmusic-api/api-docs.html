ytmusicapi

Unofficial Python 3 API for YouTube Music — emulates web client requests using cookie/OAuth auth.

Python ≥ 3.10 v1.11.5 unofficial — not endorsed by Google
Installation

Install via pip

# requires Python 3.10+
pip install ytmusicapi
Authentication

Two authentication methods are supported. OAuth is recommended for production apps.

OAuth (recommended)

Runs a one-time CLI flow, saves credentials to a JSON file.

from ytmusicapi import YTMusic, setup_oauth

# one-time setup — opens browser, saves oauth.json
setup_oauth(filepath='oauth.json', open_browser=True)

# use going forward
yt = YTMusic('oauth.json')

Browser cookies

Paste request headers from browser DevTools. Less stable than OAuth.

from ytmusicapi import YTMusic, setup

# one-time setup — follow CLI prompts
setup(filepath='browser.json')

yt = YTMusic('browser.json')

Unauthenticated

Search and browse only. No library, history, or playlist write access.

yt = YTMusic()
Initialisation
YTMusic.__init__
no auth needed

Creates a new YTMusic instance. Pass an auth file path for authenticated requests.

YTMusic(auth: str | Dict | None = None, user: str | None = None, requests_session: bool = True, proxies: Dict[str,str] | None = None, language: str = 'en', location: str = '')
Parameters
Name Type Description
auth str | Dict | None optional Path to oauth.json or browser.json, or a dict of auth headers. Omit for unauthenticated use.
user str | None optional Brand account channel ID. Use when your Google account manages multiple YouTube channels.
requests_session bool optional Reuse HTTP session across requests for performance. Default True.
proxies Dict[str,str] | None optional Proxy config passed to requests, e.g. {'http': 'http://proxy:8080'}.
language str optional BCP-47 language code for response data. Default 'en'. See ytmusicapi/locales/ for supported values.
location str optional ISO 3166-1 country code to override server-determined location, e.g. 'IN', 'US'.
Search
yt.search
no auth needed

Search YouTube Music. Returns mixed results or filtered by type. The primary entry point for finding content to play.

search(query: str, filter: str | None = None, scope: str | None = None, limit: int = 20, ignore_spelling: bool = False) → List[Dict]
Parameters
Name Type Description
query str required Search query string.
filter str | None optional Restrict results to one type: songs · videos · albums · artists · playlists · community_playlists · featured_playlists · uploads. Omit for mixed results.
scope str | None optional Restrict to 'library' or 'uploads' (authenticated only).
limit int optional Maximum number of results. Default 20.
ignore_spelling bool optional Disable autocorrect. Default False.
Returns List of result dicts. Each has resultType ('song', 'video', 'album', 'artist', 'playlist'), videoId/browseId/playlistId, title, artists, album, duration, thumbnails, isExplicit.
Example
results = yt.search('Daft Punk', filter='songs', limit=10)

for r in results:
    print(r['videoId'], r['title'], r['artists'][0]['name'])

# result shape (songs filter):
# {
#   "resultType": "song",
#   "videoId": "5NV6Rdv1h3I",
#   "title": "Get Lucky",
#   "artists": [{"name": "Daft Punk", "id": "UCWjnMTMBtT1D3ZNNFZ..."}],
#   "album": {"name": "Random Access Memories", "id": "MPREb_..."},
#   "duration": "6:08",
#   "thumbnails": [{"url": "https://...", "width": 226, "height": 226}],
#   "isExplicit": false
# }
yt.get_search_suggestions
no auth needed

Returns autocomplete suggestions for a partial query. Use this to power a live search box.

get_search_suggestions(query: str, detailed_runs: bool = False) → List[str] | List[Dict]
Parameters
Name Type Description
query str required Partial query string.
detailed_runs bool optional If True, returns run objects with text and bold fields for rendering highlighted suggestions.
Returns List of suggestion strings. If detailed_runs=True, list of dicts with text (str) and runs (list of {text, bold}).
Example
suggestions = yt.get_search_suggestions('daft p')
# ['Daft Punk', 'Daft Punk - Get Lucky', 'Daft Punk discovery', ...]

# with bold-run highlights for a search-as-you-type UI:
detailed = yt.get_search_suggestions('daft p', detailed_runs=True)
# [{"text": "Daft Punk", "runs": [{"text": "daft p", "bold": true}, {"text": "unk", "bold": false}]}, ...]

Browsing
yt.get_home
no auth needed

Returns the YouTube Music home feed — curated shelves of playlists and albums based on your listening history (or generic when unauthenticated).

get_home(limit: int = 3) → List[Dict]
Parameters
Name Type Description
limit int optional Number of shelves to load. Default 3.
Returns List of shelf dicts: {title: str, contents: List[{title, browseId, thumbnails, ...}]}

yt.get_artist
no auth needed

Returns complete artist page data including top songs, albums, singles, and related artists.

get_artist(channelId: str) → Dict
Parameters
Name Type Description
channelId str required Artist channel ID. Get this from search(filter='artists') results.
Returns Dict with name, description, views, subscribers, thumbnails, songs.results[], albums.results[], singles.results[], related.results[].

yt.get_album
no auth needed

Returns full album metadata and its complete track listing.

get_album(browseId: str) → Dict
Parameters
Name Type Description
browseId str required Album browse ID. Starts with MPREb_. Get from search results or get_album_browse_id().
Returns Dict with title, artists[], year, duration, trackCount, description, thumbnails[], tracks[]. Each track has videoId, title, trackNumber, duration, isExplicit, feedbackTokens.
Example
album = yt.get_album('MPREb_9nqEki4ZDpp')
print(album['title'], album['year'], f"{album['trackCount']} tracks")

for track in album['tracks']:
    print(track['trackNumber'], track['title'], track['videoId'])

album = yt.get_album(browse_id)
yt.get_song
no auth needed

Returns metadata and adaptive streaming URLs for a song or video. This is what you call to get playable audio stream URLs.

Streaming URLs expire after ~6 hours and may require cipher decoding. For reliable playback consider using yt-dlp alongside ytmusicapi for stream extraction.
get_song(videoId: str, signatureTimestamp: int | None = None) → Dict
Parameters
Name Type Description
videoId str required YouTube video ID.
signatureTimestamp int | None optional Current YouTube signature timestamp. Omit to use library default; providing an outdated value may produce invalid stream URLs.
Returns Dict with videoDetails (title, author, lengthSeconds, viewCount), playabilityStatus, and streamingData.adaptiveFormats[]. Each format has itag, url, mimeType, bitrate, audioQuality, contentLength.
Example
song = yt.get_song('4y33h81phKU')

# filter to audio-only formats
audio_formats = [
    f for f in song['streamingData']['adaptiveFormats']
    if 'audio' in f['mimeType']
]

# sort by bitrate, pick highest quality
best = sorted(audio_formats, key=lambda x: x['bitrate'])[-1]
print(best['mimeType'], best['audioQuality'])
print(best['url'])  # pass to audio player / requests / ffmpeg

# common audio itags: 140 = m4a/128kbps, 251 = webm/opus/160kbps
yt.get_lyrics
no auth needed

Fetches lyrics for a song. The browseId must come from get_watch_playlist()'s lyrics key.

get_lyrics(browseId: str, timestamps: bool = False) → Dict | None
Parameters
Name Type Description
browseId str required Lyrics browse ID from get_watch_playlist()['lyrics'].
timestamps bool optional Return timed lyrics (LRC-style) when available. Default False.
Returns {lyrics: str, source: str} — or TimedLyrics with .lyrics (list of LyricLine with text, start_time, end_time) when timestamps=True. Returns None if no lyrics available.
Example
watch = yt.get_watch_playlist(videoId='4y33h81phKU')
lyrics_id = watch.get('lyrics')

if lyrics_id:
    lyrics = yt.get_lyrics(lyrics_id)
    print(lyrics['lyrics'])
    print('Source:', lyrics['source'])

# timed lyrics for karaoke / synced display:
timed = yt.get_lyrics(lyrics_id, timestamps=True)
for line in timed.lyrics:
    print(line.start_time, line.text)
Playback Queues
yt.get_watch_playlist
no auth needed

Returns the playback queue that appears when you press play on a song in YouTube Music. Also returns the lyrics browse ID. Core method for building an "up next" queue.

This is the starting point for the playback flow: call this → get track list → call get_song(videoId) for stream URLs → call get_lyrics() for lyrics.
get_watch_playlist(videoId: str | None = None, playlistId: str | None = None, limit: int = 25, params: str | None = None) → Dict
Parameters
Name Type Description
videoId str | None optional Seed track video ID. At least one of videoId or playlistId is required.
playlistId str | None optional Playlist ID to generate queue from.
limit int optional Maximum number of tracks in the queue. Default 25.
params str | None optional Optional params string for radio/shuffle mode variants.
Returns {tracks: List[Dict], playlist: str, lyrics: str | None}. Each track has videoId, title, byline, length, thumbnail[], likeStatus, feedbackTokens.
Example
queue = yt.get_watch_playlist(videoId='4y33h81phKU', limit=50)

print('Queue playlist ID:', queue['playlist'])
print('Lyrics ID:', queue['lyrics'])

for track in queue['tracks']:
    print(track['title'], '-', track['byline'], track['length'])

# full playback flow:
first_track = queue['tracks'][0]
song_data   = yt.get_song(first_track['videoId'])
lyrics_data = yt.get_lyrics(queue['lyrics']) if queue['lyrics'] else None
yt.get_watch_playlist_shuffle
no auth needed

Same as get_watch_playlist() but returns tracks in a shuffled order.

get_watch_playlist_shuffle(videoId: str | None = None, playlistId: str | None = None, limit: int = 50) → Dict
Returns Same structure as get_watch_playlist().
Example
shuffled = yt.get_watch_playlist_shuffle(playlistId='PLQwVIlKxHM6rz0fDJVv_0UlXGEWf-bFys')
for t in shuffled['tracks']:
    print(t['title'])

Play History
yt.get_history
auth required

Returns the user's recently played songs.

get_history() → List[Dict]
Returns List of track dicts with videoId, title, artists[], album, duration, thumbnails[], played (date string), feedbackToken.

history = yt.get_history()

Explore
yt.get_mood_categories
no auth needed

Returns the "Moods & Genres" category tree from YouTube Music's Explore section.

get_mood_categories() → Dict[str, List[Dict]]
Returns Dict where keys are category names (e.g. 'For you', 'Genres', 'Moods & moments') and values are lists of {title: str, params: str}. Pass params to get_mood_playlists().
Example
moods = yt.get_mood_categories()
# {
#   "For you": [{"title": "1980s", "params": "ggMPOg1u..."}, ...],
#   "Genres":  [{"title": "Dance & Electronic", "params": "ggMPOg1u..."}, ...],
#   "Moods & moments": [{"title": "Chill", "params": "ggMPOg1u..."}, ...]
# }
for section, items in moods.items():
    print(section, [i['title'] for i in items])
yt.get_mood_playlists
no auth needed

Get the list of playlists for a specific mood or genre.

get_mood_playlists(params: str) → List[Dict]
Parameters
Name Type Description
params str required params token from get_mood_categories().
Returns List of {title, playlistId, thumbnails[]}
Example
moods = yt.get_mood_categories()
chill_params = moods['Moods & moments'][0]['params']
playlists = yt.get_mood_playlists(chill_params)
for pl in playlists:
    print(pl['title'], pl['playlistId'])
yt.get_charts
no auth needed

Returns trending charts data: top songs, videos, artists, and trending tracks.

get_charts(country: str = 'ZZ') → Dict
Parameters
Name Type Description
country str optional ISO 3166-1 country code e.g. 'IN', 'US', 'GB'. Use 'ZZ' for global. Default 'ZZ'.
Returns Dict with songs.items[], videos.items[], artists.items[], trending.items[] (not present for global charts). US charts include additional genres section. Songs section requires authenticated premium account.
Example
charts = yt.get_charts(country='IN')
for song in charts['videos']['items']:
    print(song['title'], song['artists'][0]['name'])
